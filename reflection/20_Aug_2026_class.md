## Topic: Creating and Structuring a Markdown File

In this class, I learned how to create and properly structure a **Markdown file**. We discussed how good formatting and organization can make a document easier to read, understand, and maintain.

## What I Learned

- Learned how to create a Markdown file using the `.md` extension.
- Understood how to use **headings and subheadings** to organize content.
- Learned how to use **bullet points and numbered lists** for presenting information clearly.
- Understood the importance of keeping related information together.
- Learned how to write explanations that are **short, clear, and specific**.
- Understood that consistent formatting makes a document easier to read.
- Learned that a reflection should include the **topics discussed, important concepts, and personal learnings**.

## Structure of a Reflection

A good Markdown reflection can be organized into:

1. **Title or heading** – Gives the date or topic of the class.
2. **Topics discussed** – Lists the main concepts covered.
3. **Discussion** – Briefly explains what was learned.
4. **Personal reflection** – Includes important observations and takeaways.

## Key Takeaway

This class helped me understand that Markdown is not just about writing text, but also about **organizing information in a clear and readable way**. A properly structured Markdown file makes it easier to read, review, and maintain the content.
