# Reflection — 29 September 2026
**CSC360 Group Project: Master-Detail Application**

During this session, I continued working on our JavaFX-based Master-Detail Application. My focus was on understanding the implementation in greater depth, reviewing the code structure, and exploring how different JavaFX components work together to provide the application's functionality.

### Work and Progress

1. **Understanding the Master-Detail Implementation:** I explored how the master-detail functionality is implemented in the application. I focused on understanding how selecting an item from the master section updates the information displayed in the detail section. This helped me understand the connection between the user interface and the underlying application logic.

2. **Exploring the Main Application Classes:** I reviewed the `MainApp` and `MasterDetailApp` classes to understand their responsibilities and how the application is initialized and executed. I also explored how different classes interact to maintain the application's overall functionality.

3. **Understanding Event Handling:** I studied how JavaFX event handling is used to respond to user interactions. I understood how actions performed by users, such as selecting an item, trigger corresponding methods and update the interface. This helped me understand how interactive applications respond to user input.

4. **Reviewing Java Concepts in the Code:** While going through the implementation, I explored concepts such as method overriding using `@Override`, class inheritance, object creation, and the use of different packages. I understood how these concepts contribute to organizing the code and implementing the required functionality.

5. **Understanding Code Organization:** I reviewed how the project separates different responsibilities across classes and packages. This helped me understand why organizing an application into smaller components is useful for readability, maintenance, and future modifications.

### Technical Understanding and Learning

This session helped me understand the practical implementation of JavaFX beyond simply designing a graphical interface.

I gained a better understanding of how event handlers connect user actions with application functionality. I also learned how methods are overridden when a class provides its own implementation of an inherited method, and why annotations such as `@Override` are useful in Java.

Additionally, I understood how the master-detail pattern helps present information efficiently by maintaining a list of items alongside the details of the currently selected item.

Reviewing the code also helped me understand the importance of packages and separate classes in maintaining a structured Java application.

### What I Learned

Through this session, I improved my understanding of:

- Implementing the Master-Detail design pattern using JavaFX.

- Connecting user interactions with application functionality through event handling.
- Using method overriding and understanding the purpose of `@Override`.
- Organizing Java code using classes and packages.
- Understanding how different components communicate within a JavaFX application.
- Separating interface-related responsibilities from application logic.

I also realized that understanding the complete flow of an application is important. Rather than looking at individual methods separately, it is necessary to understand how they work together to produce the expected output.
